# Blasphemous LocalizationPatcher
---

## Features

- Supports adding custom language localization to Blasphemous
- Supports editing existing localization texts by customizable language patches
- Supports changing fonts of displayed languages using system fonts & self-built font AssetBundles.
- Supports customizing language appearance order/toggle (as appeared in the "Settings" tab of Blasphemous) in configle file

## Usage and Tutorial can be found here -> [tutorial doc](docs/tutorial.md)

## Bug report

If any bug occurs, locate your log file at `[your Blasphemous directory]\BepInEx\LogOutput.log`, and open an issue [here](https://github.com/EltonZhang777/Blasphemous.LocalizationPatcher/issues) or DM NewbieElton (discord id: eltonzhang777) on Discord.

If in the very unlikely case (no known issue nor occurences lead to this, though) that an error occured during the pre-patching process, the mod will remove all languages in the game, leaving the whole game without any text.
- Check if any corrupted language patches/fonts/AssetBundles is causing this before reporting bug.
